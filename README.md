# Sistemas Distribuídos

Repositório pessoal de **estudos** da disciplina de Sistemas Distribuídos —
material da disciplina (exemplos, PDFs, anotações de aula) e as resoluções dos
meus TDEs (Trabalho Discente Efetivo). Não é um projeto de produção nem um
material oficial da disciplina; é o meu apoio de estudo.

## Estrutura

- **`1-periodo-anterior/`** — período em que cursei a disciplina e fui reprovado.
  Contém apenas os TDEs entregues na época (`tdes/TDE 01`, `TDE 02`, `TDE 03`),
  mantidos aqui como referência.

- **`2-periodo-atual/`** — período atual, cursando a disciplina novamente.
  - `tdes/` — resoluções dos TDEs entregues neste período.
  - `exemplos/` — exemplos de código passados pelo professor em aula.
  - `pdfs-aula/` — PDFs/slides usados nas aulas desta disciplina.
  - `pdfs-revisao-outra-materia/` — PDFs de revisão de Java usados no primeiro
    dia de aula, mas pertencentes a outra disciplina.
  - `notas-quadro.md` — transcrição de anotações feitas no quadro branco
    durante as aulas.
  - `enunciados-tdes.md` — enunciados dos TDEs propostos pelo professor.

## Observação

O código dos TDEs é meu, feito como exercício de aprendizado — pode conter
erros ou soluções não ideais. Os exemplos e PDFs são material do professor,
mantidos aqui só para consulta pessoal.
